# figure/caption-separated

Supports a standard `<figure>` with one authored `<img>` or inline `<svg>` body and one visible `<figcaption>`. The body is measured independently of the wrapper. Reports when the page distance exceeds `maxPageDistance` (default 0). Multiple bodies, split/repeated bodies, missing/hidden geometry, clipping/masking/filter effects, multiple captions and source mismatch decline. An inline SVG needs a nonzero paint primitive intersecting its viewport; this is a DOM paint-state witness, not an ink-mask proof. Source scripts/base elements, no source-map mode and stored snapshots without the index decline inventory unavailable. Warning, off in the default profile; strict and explicit enablement run it. Cause and intent remain unknown. Paged.js's measured `data-next-break-before` metadata is excluded from body identity only after the authored inventory confirms that no source element owned that field; authored class, style, drawing attributes and content remain part of identity.
